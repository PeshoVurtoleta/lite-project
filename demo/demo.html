Zero-GC reactive draft overlays for lite-signal — stage edits without mutating the source; commit, revert, reconcile.

A projection reads through an ephemeral overlay. Type to stage a draft — the AUTHORITATIVE source is never touched. Commit writes drafts through; Revert drops them. EFFECTIVE is what get(key) returns: overlay if staged, else source.

Patch emission [1.2]. forEachPatch(fn) streams the staged drafts as fn(key, from, to) — from is the current source value, to the draft. Read-only, untracked, zero-alloc per key. By default an unchanged draft is emitted too (the stream always matches dirtyCount()); pass a skip predicate (confirmOnEcho) to drop echoes. toPatch() is the allocating cold convenience.

Overlay TTL [1.3]. set(key, v, {ttl}) stages a draft that auto-reverts when the deadline passes — the source is never touched. One re-armed timer per projection; re-set re-arms; commit / clear / revert cancel. The self-heal for a lost ack — and for object drafts, which can never echo-confirm under Object.is.

projectCRDT [1.4]. Two real lite-crdt replicas, synced op-by-op in memory. The projection drafts over replica A's LWW-Map through its fine-grained reactive get(key) — staging touches no CRDT, commit emits ops that converge B, and a write on B auto-reconciles A's drafts: an echo drops the draft, a conflict stays masked. (Object drafts never echo-confirm — lite-crdt hands back a read-only wrapper, so Object.is can't match; use {ttl} or a structural policy.)
