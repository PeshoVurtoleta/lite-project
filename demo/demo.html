lite-project v1.2.0

Zero-GC reactive draft overlays for lite-signal — stage edits without mutating the source; commit, revert, reconcile.

A projection reads through an ephemeral overlay. Type to stage a draft — the AUTHORITATIVE source is never touched. Commit writes drafts through; Revert drops them. EFFECTIVE is what get(key) returns: overlay if staged, else source.

A masked source change (source moves under an active draft) re-evaluates the projected computed but, because its output is unchanged, the consumer does not re-run — the count holds.

Optimistic UI. Stage a draft (shown instantly), then the “server” responds. On echo the authoritative value matches your draft — the overlay drops, no flicker. On conflict it differs — the draft stays masked and the row flags the divergence.
